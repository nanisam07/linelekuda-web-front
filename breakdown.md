# Project Goal

Build a modern healthcare appointment booking website similar to the reference design.

Style:

• Minimalistic
• Premium
• 3D illustrations
• Soft shadows
• Rounded corners
• Apple + Stripe inspired
• Responsive
• Light theme


Primary Objective

Allow users to:

✓ Search Doctors
✓ Book appointments
✓ Join virtual queue
✓ Get live queue updates
✓ Reduce waiting time
